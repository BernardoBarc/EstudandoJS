Exercicios de Lógica de Programação

1. Crie uma função que receba um nome e retorne uma saudação personalizada.

2. Crie uma função que receba três números e calcule a média entre eles.

3. Crie uma função que retorna se um número é negativo, positivo ou zero.

4. Crie uma função que conte quantos caracteres tem uma palavra.

5. Crie uma função que transforme celcius em Fahrenheit.

6. Crie uma função que encontre o maior elemento de um array.

7. Crie uma função que some todos os números de um array.
